# Booked

The companion code for *Mastering Multi-Agent Workflows* by Hector M Diaz.

Everything lives in [`companion/`](companion/), the same path the book uses,
so every command in the book works from the root of this repository:

```
node companion/server.mjs                     # http://localhost:3000
node --test "companion/test/*.test.mjs"      # run the tests
```

Needs Node.js 22 or newer, no packages to install. Same on Windows, macOS and Linux.
See [`companion/README.md`](companion/README.md) and [`companion/BUILD-LOG.md`](companion/BUILD-LOG.md).
